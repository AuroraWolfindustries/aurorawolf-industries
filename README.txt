IMPORTANT BEFORE PUBLISHING
1. The header currently uses a simple AW monogram placeholder because the existing AuroraWolf Industries logo file was not identifiable in the available library. To use your existing logo, add it as assets/logo.png and update the header in each HTML file to replace:
   <span class="brand-fallback" aria-label="AuroraWolf logo placeholder">AW</span>
   with:
   <img src="assets/logo.png" alt="AuroraWolf Industries logo">
   The CSS already includes styling for a logo image.
2. Replace hello@yourdomain.com with your real business email.
3. Add your official social media links and any verified business details.
4. Review division descriptions before publishing. They are framed as areas of focus, not claims that products or services are already launched.
5. The site is static. The contact area is informational and does not submit messages until a form/service is added.
6. Google Fonts are loaded from an external service; local fallback fonts will be used if unavailable.

FREE HOSTING
This folder can be uploaded to a static hosting service such as Netlify Drop. Extract the ZIP first, then upload the folder's contents (the index.html file must be at the published root). You will need to complete the hosting provider's account/setup steps yourself.
